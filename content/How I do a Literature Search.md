There are 3 steps to doing a literature search (all of them involve looking for papers because its a literature search...):
1. Use search engine to find 3 to 5 recent papers
2. Find shared citations and repeated authors
3. Find recent proceedings from top conference websites

# 1. Use search engine to find 3 to 5 recent papers.
1. Do a first pass on each paper. (See [[How I Read Papers]] for what the first pass is.)
2. Read related works section.
3. If you find a survey paper then you are lucky and no need to proceed further.

# 2. Find shared citations and repeated author names in bibliography.
1. These are key papers and researchers in this area.
2. Download key papers and set aside.
3. Go to researchers' website and look for recent publications.
4. Find top conferences.

# 3. Go to top conferences websites and find recent proceedings.
1. Add these to key papers.
2. Do 2 passes on each paper you've set aside.
3. If you find a relevant paper in the references, add it.

It all starts with a Google search, or if you're more experienced, an advanced query search in various databases e.g. Scopus. Find the 3 to 5 most recent papers and then do a first pass on each paper. Keep these papers somewhere. This will be your list of key papers. Then look at the related works section and find the commonly occuring referenced papers and authors. These indicate key papers and authors in the work. Add the key papers to the list.

Take the list of authors and head to their websites to look for their most recent publications and see where the publications were presented because these are likely the top conferences and/or journals. Go to the recent proceedings of these top conferences and these to your list of key papers.

At this point, you'll have quite a list of papers which are highly relevant to your work. Do 2 passes on each paper that you've set aside and if you find a relevant paper in the references then add it to the list.

And that's how you end up with a list of papers after doing a literature search.
