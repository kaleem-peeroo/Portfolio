# Tmux
An application for terminal multiplexing. I've set up my custom keybinds for splitting panes, creating windows, and even switching between sessions.

# visidata
A tool I use for viewing and manipulating tabular data. It uses vim motions which makes it easy to navigate the data. I've even created and used my own custom plugins e.g. I created a plugin to calculate the mean with 95% confidence interval for any column of data.
